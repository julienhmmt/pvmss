**Fichier :** `backend/api/v1/router.go` + nouveau `backend/api/v1/health.go`

```bash

GET  /api/v1/health/proxmox  → { connected: bool, message: string }
```

- `ProxmoxHealthHandler` appelle `s.GetProxmoxStatus()`

### A2. Changement de mot de passe

**Fichier :** `backend/api/v1/auth.go`

```bash

```

- Ajouter `ChangePassword` à `AuthHandler`
- Valider `current_password` via Proxmox login, puis changer via API Proxmox `PUT /nodes/{n}/users/{user}/password` ou via session
- Enregistrer dans `router.go` avec `jwtWrap`

### A3. Toggle NIC

**Fichier :** `backend/api/v1/vm_details.go`


- Ajouter `ToggleNIC` à `VMDetailsHandler`
- Lire config actuelle `net{n}`, ajouter/enlever `link_down=1`, appeler `UpdateVMConfigResty`
- Enregistrer dans `router.go` avec `jwtWrap`

## Bloc G — Makefile : cibles frontend manquantes

**Fichier :** `Makefile`

Les cibles `frontend-install`, `frontend-build`, `frontend-dev` sont dans `.PHONY` mais n'ont **pas de recette**. Les implémenter :

```makefile
frontend-install: ## Installe les dépendances du frontend Svelte
 cd frontend-svelte && npm ci

frontend-build: frontend-install ## Construit le frontend Svelte
 cd frontend-svelte && npm run build

frontend-dev: ## Lance le serveur de développement Svelte (hot reload)
 cd frontend-svelte && npm run dev
```

Vérifier que `build:` dépend bien de `frontend-build` (déjà le cas ligne 45).
